Guides

Terminal

Pick a language, write code, hit Run — it executes for real on a public runtime. Open a project's Overview tab and hit Run Website to build and preview it in the same place, with a file sidebar and live console.

Projects

Create a project, add files (or drag in a whole folder, GitHub-style), and invite people by Social ID as Viewer, Contributor, or Editor. Contributor edits land as Change Requests you approve or reject — nothing touches the real file until then.

Studio

Browse every public project on Knight — Categories, Trending, Yours, Socials, or Near You — with search, voice search, and star ratings.

Communication

Pick a friend and chat in real time over Knight's own WebSocket server — messages arrive instantly for anyone online, not on a delay.

Data-Base (Notes & Codes)

Private notes and code snippets only you can see — searchable, taggable, pinnable.

Social & Nearby Knights

Your Profile card shows your Social ID — share it for friend requests. "Go Live" on the Social page finds other Knights physically near you in real time.

Deploy

Deploy a project straight to a real link once Knight Cloud (the Java backend) is connected, or build a portable .html and host it yourself anywhere.
Game Booster

Real numbers straight from your browser's own APIs — nothing here is simulated. Knight can't reach into your OS or hardware from a webpage, but it can read what the browser exposes and tell you what that means for gaming performance.
